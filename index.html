数据获取方式

  • 榜单正文：抓取时间 2026-10-24 19:40 – 21:20（UTC+8）。静态 HTTP 抓取（豆瓣 Top 250、MyAnimeList、MyDramaList、AlloCiné 榜单页与详情页）； 对有人机验证 / 纯前端渲染的站点（IMDb、Metacritic、Rotten Tomatoes 编辑部榜、Letterboxd）用真实浏览器渲染后读取页面内嵌数据。
  • 官方公开 API：AniList 通过其官方 GraphQL 接口（graphql.anilist.co）按 averageScore 降序实时查询，电影与 TV 各 50 条；
  • 封面图：通过 IMDb 官方图片服务按「片名 + 年份 + 类型」匹配，命中 664/725 条；标题必须实质匹配（同词 / 包含 / 年份吻合）才采用，未命中显示占位色块，不使用猜测图。
  • 工具：Python（urllib / JSON 解析 / 并发抓取）、Playwright + Edge（受限站点渲染）、openpyxl 与自写模板生成交付文件。

数据性质区分

  • 官方榜单原文：豆瓣、IMDb、Rotten Tomatoes、Metacritic、Letterboxd、MyDramaList、MyAnimeList、AlloCiné —— 排名 / 片名 / 评分 / 评分人数直接来自榜单页或官方接口。
  • 官方公开 API 实时查询：AniList（GraphQL）。
  • 人工整理 / 翻译：① 中文译名；② 原始语言与制片地区；③ 「折算/10」列（百分制÷10、5 分制×2 的线性换算，仅便于跨平台排序，不等于各平台分数等价）。

评分制差异

  • 百分制：Metacritic Metascore（影评加权分）、Rotten Tomatoes Tomatometer（影评人好评百分比）、AniList Average Score（用户加权分折算）——三者含义完全不同。
  • 10 分制：豆瓣、IMDb、MyAnimeList、MyDramaList。
  • 5 分制：Letterboxd、AlloCiné 观众评分。

收录原则与已知局限

  • 仅收录第三方评分 / 评分机构类平台的公开榜单；已排除流媒体自有榜单（腾讯视频、爱奇艺、优酷等）与播放量排行。
  • 每平台每榜取前 50 条；榜单本身不足 50 条时按实际条数收录并标注，不用推测数据补齐 —— 目前仅 Rotten Tomatoes 剧集榜（RT25，25 条）属于此情况。
  • 豆瓣没有剧集固定总榜（不存在「剧集 Top 250」一类榜单，只有每周更新的口碑周榜），因此剧集部分不收录豆瓣，避免把当期周榜当成历史总榜。
  • Rotten Tomatoes 无全时段纯算法榜：电影为编辑部《300 Best Movies of All Time》，剧集为编辑部《RT25》。
  • Letterboxd 不对未登录用户开放「全站按评分排序」浏览页，电影部分采用其官方账号维护的 Top 500；该平台不提供剧集榜单。
  • Metacritic 榜单页标注北美上映 / 首播日期，部分老片与首映年份不同。MyDramaList 榜单页未公开评分人数，该列留空。
  • 所有榜单均为「全时段总榜」类（按评分 / 影评排序），不收录年度榜、周榜等时效性榜单。
  • 朝鲜等国家 / 地区不存在公开评分数据（无民用互联网评分平台），因此无法收录，也不会编造。
